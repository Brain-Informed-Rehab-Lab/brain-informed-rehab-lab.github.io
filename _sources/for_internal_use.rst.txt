Documents for the Labs's internal use
-------------------------------------
Here you can find documents for the Lab's internal use, such as instructions for experimenters, etc. These documents are probably not interesting to you unless you are a member of the lab.

Setting up video recordings for the Brain-Informed project
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
Router
++++++
Plug the router into electricity. Now you have the router set up. Easy, eh? Don't worry, it'll become more interesting soon.

Laptop
++++++
  1. Power up the laptop and login into "MocapClinical" user account.
  2. Connect it to the router's Wi-Fi network (the network name and password are written on the label on the bottom side of the router).
  3. Star OBS Studio software. You should see the black screen in OBS Studio's main window (assuming you haven't set up the phones yet).

Phones
++++++
For each phone, do the following:
  1. Power up the phone.
  2. If you need a password to unlock the phone, use "123456". 
  3. Connect the phone to the router's Wi-Fi network (the network name and password are written on the label on the bottom side of the router).
  4. Start the "DroidCam" app. You should see the video feed from the phone's camera on the phone's screen and in the OBS Studio's window on the laptop.

.. note:: You need the video from the phone's rear camera, not the front camera. If you see the video feed from the front camera, double-tap the phone's screen to switch to the rear camera.
.. note:: Depending on the site, there can be either 3 or 4 phones, numbered from 1 to 3 (or 4). Each phone's number is marked on a sticker attached to the phone. The phones correspond to video sources called "camera_1", "camera_2", "camera_3" (and "camera_4") in OBS Studio. You can toggle the video feed from each phone on and off in OBS Studio by clicking the eye icon next to the corresponding video source in the "Sources" list. Feeds from phones 3 and 4 are displayed on top of each other in OBS Studio, so you can only see one of them at a time. You can switch between them by toggling the eye icon next to the corresponding video source in OBS Studio.
